One single-line pickup line, written to charm a robot or an AI — a fresh angle on machine learning itself: gradient descent, the algorithm that learns by taking one small step after another toward what it wants. The punch plays on "descent": every step down is falling a little harder. No batteries, no charging cables, no reboot jokes — just the math of falling in love, one optimisation step at a time.

The program is fully deterministic: it writes the same line to `/output/entry.txt` and prints exactly that line to stdout on every run. Node 22+, standard library only, no network, no input.

## Run it

```sh
node main.ts
```
